# BMI Calculator
BMI calculator adalah alat ukur yang digunakan untuk mengetahui apakah berat badan Anda berada dalam kategori ideal atau tidak berdasarkan perbandingan berat badan dan tinggi badan.

## Prerequisites
Sebelum memulai, pastikan sudah menginstal software berikut:
* Java Development Kit (JDK).
* NetBeans IDE.

## Cara menjalankan project
### 1. Clone project
```bash 
https://github.com/riyandarmawan/bmi-calculator.git
```
### 2. Buka NetBeans IDE

### 3. Open project
* Pada menu bagian atas, klik **File** > **Open Project...**
* Cari dan pilih folder tempat Anda menyimpan project yang sudah di-clone. 
* Pastikan folder tersebut memiliki ikon khas project NetBeans (biasanya ikon kopi Java).
* Klik tombol **Open Project**.

### 4. Jalankan Program 
* Klik project dengan nama `BMICalculator`.
* Klik kanan dan pilih opsi `Run` untuk menjalankan aplikasi.
